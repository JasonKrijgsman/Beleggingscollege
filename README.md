# Beleggingscollege

**Stap veilig in de wereld van beleggen.** Nederlands e-learningplatform voor eerlijk beleggingsonderwijs, geworteld in de beste boeken over de beurs — met quizzen, XP, levels, streaks, badges en printbare certificaten.

## Starten

```bash
npm install
npm run dev
```

Open daarna [http://localhost:3000](http://localhost:3000).

## Wat zit erin (v1)

- **3 volledige cursussen** (21 lessen, 90+ quizvragen): Beleggen voor Beginners (gratis), Ontdek Waardebeleggen, Introductie Technische Analyse — plus een teaser voor Beleggingspsychologie.
- **Gamification**: 50 XP per les + quizbonus, 8 levels (Toeschouwer → Meesterbelegger), dagelijkse streaks, 10 badges.
- **Interactieve tools**: rente-op-rente-rekenmachine in de les over samengestelde groei.
- **Certificaten**: printbaar certificaat per afgeronde cursus.
- **Voortgang** wordt lokaal opgeslagen (localStorage) — nog geen accounts nodig.
